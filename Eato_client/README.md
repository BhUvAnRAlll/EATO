# EATO

Fitness meal delivery and tracking app for India, built with Expo.

## Get started

```bash
npm install
npx expo start
```

For production builds, set `EXPO_PUBLIC_API_ORIGIN` to the HTTPS origin where the Expo Router API server is deployed. The production Expo config uses this as the router origin, and fails if it is missing. Leave it unset during local development so Expo Router uses the development server.
