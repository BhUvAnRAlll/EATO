EATO Super Admin portal: screens and workflow

Captured from the running prototype at phone width, signed in as the Super admin demo account (Maya Ortiz). Click any image to open it full size. The full written workflow is in ADMIN_WORKFLOW.md.

1. Overview

Switch account (demo) → Super admin → Overview: stat tiles, Attendance and Kitchen orders buttons, a To-do list that opens the fixing screen, and the admin activity log.

2. Users

Search and filter users. Verify trainers, suspend or reinstate accounts. Suspension hides posts and removes trainers from search.

3. Gyms

Create a gym (14-day trial, assign owner), change plan (recorded only), suspend a gym to hide it from Explore.

4. Reports

Reports grouped by post with reasons and reporters. Remove, Dismiss, or Suspend the author. Gym posts are shared with the owner's Review queue.

5. Content

Create and edit Home promotions with a live preview. Save draft, publish, pause, reorder. Only live ones show on members' Home.

6. Kitchen orders

Move trainer-placed meal orders: Start preparing → Send out → Mark delivered. Members track each step.

7. Attendance

All gyms or one gym. Today, History, Failed scans, and per-gym check-out QR with download, on/off and regenerate.
